## Flight recorder

`flight/` holds 25 Hz dumps of the firmware's flight recorder (PWM, encoders, gyro, ToF,
accelerometer), readable with `tools/sim/flight_report.py`. `final-demo-run_log.jsonl` is the
log submitted with the final code.
